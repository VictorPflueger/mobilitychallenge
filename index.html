    Still on this screen? Dispatch Lab has to be served over http or https. Browsers block its program modules when index.html is opened straight from disk, at an address starting with file://.

    To run it on your computer, open a terminal in this folder, run python -m http.server 8000, then open http://localhost:8000. Published on GitHub Pages, it works as is.
